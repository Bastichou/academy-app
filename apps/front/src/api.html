What this app does
This frontend ships no data of its own — every list, value and status you see is fetched live from the academy API. The app runs on cloud infrastructure, not on your laptop, so the only thing that matters here is whether the browser can reach that API and whether it's configured correctly. Run the system check below, then pick a module to call it.

The endpoint is read from window.API_BASE in config.js, which is regenerated at container startup from the API_BASE environment variable.

Empty → same-origin /api/*, proxied by Nginx (the default).
Override → point the front straight at a backend host. The target API must then allow CORS.
