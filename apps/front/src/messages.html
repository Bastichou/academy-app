01 — Messages
Persistent Message Board
Post messages with a text body and author name, then retrieve the full list. The storage backend is swappable at runtime — in-memory by default, upgrades to Redis or a cloud database via environment variables. Use GET /api/config to inspect which backend is currently active.
required env vars
None — works out of the box.
In-memory storage is active by default. Data is lost on container restart.
Set REDIS_URL to persist messages in Redis, or set AZURE_STORAGE_CONNECTION_STRING for cloud storage.
// debug tips
Empty list [] from GET /api/messages Expected on a fresh start — no messages have been created yet. Use POST to add the first one.
Messages lost after restarting the container In-memory storage is ephemeral. To persist data across restarts, configure a backend: REDIS_URL or a cloud storage connection string.
400 on POST /api/messages The text field is required and cannot be blank. author defaults to "Anonymous" if omitted.
500 on any endpoint Server-side error. Check the API container logs: docker compose logs api
